# Archee Studio Homebrew tap

```bash
brew install archee-studio/tap/archee-cli              # the command line
brew install --cask archee-studio/tap/archee-desktop   # the desktop app
```

Formulae and casks are updated automatically with each release. See [archee.studio](https://archee.studio) and the [Archee Studio repositories](https://github.com/Archee-Studio).
